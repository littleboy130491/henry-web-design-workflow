# 06 — Find Design References

**Reads:** `outputs/01-site-brief.md`, `outputs/02-persona-journey.md`, `outputs/03-key-factors.md`, any references in `inputs/`
**Writes:** `outputs/06-references.md` (+ screenshots in `outputs/06-references/`)

## Task
Collect real website references that fit the brand, audience, and message, and pull out what exactly to borrow from each.

## Steps
1. Start with references the client gave (if any) and note what they seem to like about them.
2. Search for 8–12 strong references: direct competitors (to know the baseline and how to stand out), best-in-class sites in the same industry, and sites from other industries that solve a similar communication problem well. Galleries like Awwwards, Godly, Land-book, Lapa Ninja, SiteInspire, One Page Love, Mobbin are good sources.
3. Visit each one, take screenshots of relevant sections (desktop and mobile when useful).
4. Don't pick sites only for looking pretty — each must fit the persona and the "show, don't tell" strategy.

## Output structure
- **Competitor baseline** — what competitors all do (the cliché to avoid) and gaps we can win.
- **Per reference:** URL, screenshot path, why it fits, **what to borrow** (be specific: "hero with full-bleed product video and a single CTA", "pricing table with 3 tiers and a highlighted middle"), what to avoid.
- **Mood summary** — 3–5 adjectives for the visual direction, with the reasoning tied to the persona.
- **Direction options** — 2 distinct visual directions (name + 3-line description + which references support it), with a recommendation.
