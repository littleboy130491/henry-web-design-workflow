# 04 — Sitemap & Information Architecture

**Reads:** `outputs/01-site-brief.md`, `outputs/02-persona-journey.md`, `outputs/03-key-factors.md`
**Writes:** `outputs/04-sitemap.md`

## Task
Design the smallest site structure that walks the persona through their journey to the primary conversion.

## Steps
1. Start from the journey map: every page must have a job in that journey. If a page has no job, cut it.
2. Decide the sitemap, then the section order for each page.
3. Plan navigation and conversion paths.

## Output structure
- **Sitemap** — tree (mermaid diagram or indented list) with URL slugs.
- **Navigation** — header items (max ~5–6), header CTA, footer contents, mobile menu.
- **Per page:**
  - Purpose (one sentence) and which persona/journey stage it serves.
  - Primary CTA and secondary CTA.
  - **Section list in order** — for each section: name, the question it answers for the visitor, content type (text, image, grid, testimonial, form…), and which key factor from step 03 it delivers.
- **Conversion paths** — 2–3 typical visitor routes (entry page → … → conversion).
- **Shared components** — sections reused across pages (CTA band, testimonial block, contact form, etc.).
- **SEO basics** — target keyword/search intent per page, title tag and meta description draft.
- **Out of scope / later** — pages that could come later (blog, careers, etc.).
